# Role — the human

You are the lead pilot, the student, or both. The harness does not outrank you. You outrank it by aiming it, and by refusing work that will not say what it gives up.

## Before you paste a brief

1. Fly the published trainer for five minutes if you have not this week. You are about to change something you should still be able to feel.
2. Read the chapter. If the **Given up** section is hand-waving, do not aim a harness at it. Rewrite that section first. It is the real work.
3. Pick the harness from the chapter's line, not from whichever window is already open.
   - One file, one behavior → Grok CLI.
   - A seam between model, picture, and panel → OpenCode.
   - Copilot may fill either coding role, but name which role's rules it follows.
   - A URL and a license → OpenClaw or your own browser. Then a coding harness, in a **second** session.
4. Paste `docs/templates/agent-brief.md` with the chapter id filled in.

## Cockpit work

Use [the shared cockpit view plan](../quests/cockpit-view-plan.md) as the
handoff source for every harness. S2, Q-panel, and Q-views are complete locally,
as are S3–S8 and all eight written side quests. Do not reopen completed work.
The AI-student run was explicitly approved to work through that sequence.
Assign one writer per quest, even if a second harness could work on a different
file; the panel and camera meet in the same scene.

The supplied screenshot and web references are visual guidance only. Keep the
Field 28 trainer generic, draw cockpit parts procedurally, and do not add
third-party cockpit art, logos, or branded aircraft names to the product.

## While it works

- If it edits a file outside `Touches`, stop it.
- If it wants to add accounts, authoritative room physics, a second `step`, or
  a downloaded airplane, stop it and point at `docs/07-trainwrecks.md`. S8's
  explicitly approved encrypted signaling mailbox is not a physics server.
- If it "finishes" without running the test, it is not finished. Ask it to run the test. If it cannot, the chapter is not done.

## At the commit point

- Read the diff. You are looking for a second theory of lift, a new network call the chapter did not name, and a placard that now lies.
- Commit with `docs/templates/commit.md`. The history of this repo is the book. A message like `update` throws a chapter away.
- Push when you mean to publish, not when the harness offers.

## When you are learning

Keep a `Stopped at` note when you quit for the day. The next session, yours or an agent's, should be able to start from that note without asking you what you meant.

You are allowed to skip a side quest forever. You are not allowed to skip a spine test and call the next chapter open. The published site is the promise that S0 is real. Do not break that promise to reach P7 faster.

## What you owe the next student

A main branch that flies, a chapter that says what it cost, and a commit that names the harness. That is the whole course.
